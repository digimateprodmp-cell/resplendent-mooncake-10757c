# Drop real campus photos here

The Hero globe automatically looks for a square photo at each of these paths.
If found, it replaces the gold monogram badge with the real photo (circular
crop, gold ring kept). If the file is missing, the monogram badge stays —
nothing breaks either way.

Expected filenames (square images, 400×400px or larger recommended):

- harvard.jpg
- oxford.jpg
- stanford.jpg
- mit.jpg
- cambridge.jpg
- yale.jpg
- imperial.jpg
- nus.jpg

No code changes needed — just add the files with these exact names and
rebuild the site.
